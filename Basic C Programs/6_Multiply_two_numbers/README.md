# Multiplication of Two Numbers

This is a basic C program that takes two integer numbers as input from the user using the `scanf()` function and calculates their multiplication using the `*` operator.

The program uses `int` variables to store the two input numbers and the result of the multiplication.

The `scanf()` function is used to take integer input. The `%d` format specifier is used because the variables `num1` and `num2` are declared as `int`.

The statement `result = num1 * num2;` multiplies `num1` by `num2` and stores the result in the `result` variable. The `printf()` function is then used to display the calculated result.

## Output

Enter number A: 6

Enter number B: 5

The multiplication of A and B is 30
